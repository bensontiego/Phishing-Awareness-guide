# How to Report a Phishing Attempt

## If you only received a suspicious message
1. Do not reply, click links or open attachments.
2. Forward the message as an attachment to the security team: `report@example.edu`.
3. Delete the message once the security team confirms receipt.

## If you clicked a link or entered details
1. **Disconnect** the device from the network if you suspect malware.
2. **Change your password** immediately from a different, trusted device.
3. **Enable or review MFA** on the affected account.
4. **Report the incident straight away** - speed limits the damage.
5. Complete `templates/incident-report-template.md` and send it to the SOC.
