# Phishing Awareness Guide
 
A beginner-friendly guide and checklist that helps students and staff **spot, avoid and report phishing attacks**.
 
> **Campaign slogan: ** Pause. Check. Protect.
 
## Why this project exists
 
Phishing is the most common way attackers gain access to accounts and networks. One convincing email can lead to stolen passwords, malware infections or data breaches. This resource gives everyday users a simple routine to follow before they click.
 
## What is inside
 
| Path | Description |
|------|-------------|
| `docs/01-what-is-phishing.md` | What phishing is and the common types |
| `docs/02-red-flags-checklist.md` | A quick checklist for suspicious emails and messages |
| `docs/03-how-to-report.md` | What to do and who to contact if you spot or fall for phishing |
| `templates/incident-report-template.md` | A template for reporting a cybersecurity incident |
 
## How to use it
 
1. Read the guide in `docs/01-what-is-phishing.md`.
2. Keep the checklist in `docs/02-red-flags-checklist.md` handy and run through it whenever a message feels unusual.
3. If something looks wrong, follow `docs/03-how-to-report.md` and fill in the incident template.
 
## Key rules to remember
 
- **Pause** - urgent or threatening messages are a warning sign.
- **Check** - verify the sender, the link and the request using a second channel.
- **Protect** - never share passwords; use multi-factor authentication (MFA).
