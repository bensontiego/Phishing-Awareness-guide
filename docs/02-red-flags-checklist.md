# Phishing Red Flags Checklist

Run through this list **before** you click, reply or open an attachment.

## The sender
- [ ] Does the email address match the real organisation exactly (watch for `paypa1.com` or extra words)?
- [ ] Is this an unexpected message from someone you normally do not hear from?
- [ ] Is the greeting generic ("Dear customer") instead of your name?

## The message
- [ ] Does it create **urgency** or threaten consequences ("act within 24 hours")?
- [ ] Does it ask for a password, PIN, card number or one-time code?
- [ ] Does it offer something too good to be true (prizes, refunds)?
- [ ] Are there spelling mistakes or unusual wording?

## Links and attachments
- [ ] Does the link address shown when you **hover** differ from the text?
- [ ] Is the link shortened or does it use an unfamiliar domain?
- [ ] Is the attachment unexpected, or a type such as `.exe`, `.zip` or a macro-enabled file?

## If you tick ANY box
1. **Do not click** or download anything.
2. **Verify** the request using a trusted channel (call the number on the official website).
3. **Report** it - see `03-how-to-report.md`.
